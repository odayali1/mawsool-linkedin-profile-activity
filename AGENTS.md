# LinkedIn Activity Scraper

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-profile-activity` on Apify: https://apify.com/oday/mawsool-linkedin-profile-activity
- Send a profile URL you already have. You get recent likes, comments, and post links you can use to personalize outreach.
- Starting from $0.45 per 1,000 profiles.
- Use it when: You want something the person just did, before you write.
- Use something else when: You want the job history or the full profile. Use the Experience Scraper or the LinkedIn Profile Scraper.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.
